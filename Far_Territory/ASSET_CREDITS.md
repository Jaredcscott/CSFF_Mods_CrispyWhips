# Asset Credits

Artwork shipped in this package, with its source and terms.

## Card art (`Resource/Picture/`)

Every picture in `Resource/Picture/` was made for this mod. Each was generated with the
Nano Banana 2 image model through OpenArt from a written description of the card, chosen by the
maintainer, and then finished in GIMP: the white paper keyed to transparency and the image cropped
to its subject. Exported base-game card sprites were passed to the model as style references, so
the pictures follow the base game's flat, outlined look; no base-game image is copied into this
package. The generation record for each picture (its prompt and model) is in `.art/`, one JSON file
per image.

No art, text or data from Card Survival: Tropical Island is included. The island recreates that
game's island as a tribute, with names and its map's links as the only things carried over; every
picture, description and number here is new.

## Base-game sprites used directly

A few cards draw a sprite that ships with Card Survival: Fantasy Forest itself, referenced by name
and never included in this package: the River Mouth's paper-map picture (`RiverShore`) and the
status icons of the remedy effects.

## Adding artwork

When adding external, commissioned, AI-generated, or derived artwork, record the source,
author/tool, license or terms, and any attribution text here before publishing the mod package.
