**Content**: 0 items / 0 blueprints / 0 structures / 0 perks / 0 images (C#-only utility mod).

**Shipped in 0.1.1 (unreleased)**: Hide Rain And Snow Effects (U1), Clock Format (U2), equipped-container hotkeys (B4), Lock Toggle with padlock mark and the Quick Transfer and Repeat Action lock bridges (B1), Sort Container (B2), Capacity And Warmth Readouts (B3), Quickswap When Equipping (B5), Sealed mark (B6), Character randomiser (U4), and for Repeat Action Auto-Pull Materials (C1), Store Products In (C2) and Equip Spare Tool On Break (C3). Every option beyond the lock and the randomiser button defaults off.

**Framework compliance**: N/A by design: UTILITY mod with no `[BepInDependency]`; the bundled Quick Transfer and Skill Speed Boost need the framework.
